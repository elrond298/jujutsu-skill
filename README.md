# jujutsu skill

Agent skill for working with [Jujutsu](https://jj-vcs.github.io/jj/latest/) (jj), the Git-compatible VCS with mutable commits and automatic rebasing. Reviewed with jj v0.44.0.

**Load this skill first whenever a repository contains a `.jj` directory.**

## Contents

- [`SKILL.md`](SKILL.md) — core concepts, essential workflow, and command usage: describe-first commits, squash/edit workflows, split/absorb/abandon, rebase, bookmarks, workspaces, git integration, conflicts, and agent-safe flags (`--no-pager`, `-m`, `-u`).
- [`references/`](references/) — focused guides: operation log, conflicts, colocated repos, git command translation, FAQ, GitHub, Windows, installation, revsets, anonymous branches and merging.
